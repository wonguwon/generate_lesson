기준일 2026-10-28. 아래 숫자는 자료 파일을 Python으로 다시 열어 계산한 값이고(`_tools/check_materials.py`), 모두 교안의 정답 표와 같습니다.

## 차시별 자료 구성

| 차시 폴더 | 수강생이 받는 시작 상태 |
| --- | --- |
| 01_codex-agent | `다온유통_영업지원팀` 바로 안에 파일 8개 (원본/출력 폴더는 수업 중에 직접 만듦) |
| 02_permissions-git | 1차시 끝 상태: `원본`(8개) + `출력/폴더요약.md` |
| 03_batch-files | 2차시 끝 상태(`폴더요약.md` 제목 변경, `반품요약.md`) + 프로젝트 밖에 `9월_일보`(30개)·`영수증`(6장) |
| 04_outputs-edit | 3차시 끝 상태: 원본에 9월 일보·영수증, 출력에 이름 변경·형식 변환·통합 결과 |

- `.git` 폴더는 넣지 않았습니다. 2차시 수업에서 Codex가 저장소를 만듭니다. 3차시 이후 폴더로 **중간부터** 시작하면 저장 지점 기록이 없으므로, 시작할 때 "이 폴더를 Git으로 관리하게 설정하고 지금 상태를 저장 지점으로 남겨줘"를 먼저 하게 하고, 저장 지점 수(2→4→7→11)는 그만큼 다르게 나온다고 안내합니다.
- 바탕 화면 `메모.txt`(2차시)는 수강생이 직접 만드는 파일이라 자료에 넣지 않았습니다.
