# Work 모드 첫 작업 - 실습 파일

교안: [Work 모드 첫 작업](https://app.notion.com/p/36f435fcbd9d837fba4f012b18eed45c)

이 차시의 실습은 모두 자료를 채팅창에 붙여넣는 방식이라, 학습자가 올릴 파일은 없습니다.
아래 파일은 붙여넣을 자료와 요청문을 한곳에 모은 것, 그리고 강사가 정답 대조와 시연에 쓸 파일입니다.

## 학습자용 (수업 자료로 배포)

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| 협업툴_요금안내.txt | 그럴듯한 첫 답 ~ 결과는 열어 봐야 안다 | 교안의 [자료] 블록 그대로. 가상 서비스 5곳의 요금 조건 |
| 실습_요청문.txt | 전 섹션 | 교안의 요청문을 순서대로 모은 것. "(여기에 실습 자료를 붙여넣기)" 자리에 요금 안내를 붙여넣음 |

두 파일 모두 UTF-8(BOM)으로 저장해 Windows 메모장에서 한글이 깨지지 않습니다.

## 강사용 (배포하지 않음)

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| 정답_요금비교표.xlsx | 결과는 열어 봐야 안다 | 시트 3개: 5곳 정답(10명·월간·부가세 포함), 방향을 바꾸기 전 3곳 정답, 생길 수 있는 실수 |
| 시연용_오답예시_도란보드부가세누락.xlsx | 결과는 열어 봐야 안다 | 도란보드 부가세가 빠져 99,000원·4위가 된 결과 파일(틀린 칸 표시). Work가 틀리지 않았을 때 "짚어서 수정 요청"을 보여 주는 화면용 |

## 정답 요약 (10명 팀, 월간 결제, 부가세 포함)

| 순위 | 서비스 | 10명 팀 월 요금 |
| --- | --- | --- |
| 1 | 업무콩 | 82,500원 |
| 2 | 플랜고래 | 94,000원 |
| 3 | 팀솔솔 | 97,000원 |
| 4 | 일감나루 | 100,000원 |
| 5 | 도란보드 | 108,900원 |

방향을 바꾸기 전 3곳: 플랜고래 94,000원 → 일감나루 100,000원 → 도란보드 108,900원
