# 파일 맡기고 결과 파일 받기 - 실습 파일

교안: [파일 맡기고 결과 파일 받기](https://app.notion.com/p/e26435fcbd9d828cae9f8118b5761729)

## 학습자용 (수업 자료로 배포)

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| 강남점_1주차.csv 외 4개 | 붙여넣기에서 파일로 ~ 짚어서 한 번 더 | 교안의 [자료] 블록 그대로. 지점별 1주차 판매 원본. 일부러 넣은 문제(형식 혼재·중복·빈칸·천원 단위·영어 열 이름)가 그대로 들어 있음 |
| 실습_요청문.txt | 전 섹션 | 교안의 요청문을 순서대로 모은 것 |

CSV와 텍스트는 UTF-8(BOM)으로 저장해 엑셀·메모장에서 한글이 깨지지 않습니다.

## 강사용 (배포하지 않음)

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| 정답_대전점_1주차_정리.xlsx | "정리"의 뜻은 내가 정한다 | 정리 규칙대로 만든 정답(9행, 476,000원, 미기재 2칸). 학습자의 정리가 실패해 병합 실습을 못 할 때 대신 나눠 줄 수 있음 |
| 정답_하루담리빙_1주차_병합(고치기 전).xlsx | 열 이름이 달라도 하나로 | 열 짝대로만 합친 상태(47행). 부산점 중복과 대구점 천원 단위가 그대로 남아 1,873,271원 |
| 정답_하루담리빙_1주차_최종.xlsx | 짚어서 한 번 더 | 고친 뒤 정답(46행, 2,054,000원). 다음 차시 실습 파일과 같음 |
| 정답_대조표.xlsx | "일치"도 숫자로 다시 본다 ~ 짚어서 한 번 더 | 정리 전후, 대조표 정답, 병합 상태별 합계, 고친 뒤 정답, 일부러 넣은 문제 |
