## 학습자용 (수업 자료로 배포)

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| 하루담리빙_1주차_최종.xlsx | 전 섹션 | 앞 차시에서 대조·재작업까지 끝낸 1주차 데이터. 데이터 시트 하나, 46건, 수량 128개, 2,054,000원. 앞 차시 파일이 없는 학습자용 |

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| 정답_보고서_발표자료_숫자.xlsx | 전 섹션 | 지점별·상품별·일자별 정답, 직접 계산 3개, 생길 수 있는 실수, 발표자료 장 구성, Sites 미리보기 확인표 |
| 예시_하루담리빙_1주차_실적보고서.docx | 숫자는 계산, 문장은 이어 쓰기 | 요청 규칙대로 만든 보고서 예시(목차 5개, 비중 소수 첫째 자리, 사실만). 다음 차시에서 "지난주 보고서"가 필요한데 학습자 보고서가 없을 때 대신 쓸 수 있음 |
