## 학습자용 (수업 자료로 배포)

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| 하루담리빙_주간보고_양식.docx | 업무 하나에 작업 공간 하나 (프로젝트 참고 파일) | 교안 [자료] 블록 그대로. 목차 5개와 표의 열만 있고 숫자 없음 |
| 하루담리빙_용어정리.txt | 업무 하나에 작업 공간 하나 (프로젝트 참고 파일) | 지점·단가·건수·주차의 뜻 |
| 하루담리빙_2주차_최종.xlsx | 다음 주에는 파일만 바꿔서 | 2주차 데이터. 데이터 시트 하나, 51건, 수량 147개, 2,332,000원 |
| 하루담리빙_2주차_최종.csv | 다음 주에는 파일만 바꿔서 | 같은 데이터의 CSV(교안 [자료] 블록 그대로). xlsx를 열 수 없을 때 |
| 프로젝트_지침_5줄.txt | 매번 함께 들어가는 글, 지침 | 프로젝트 설정의 지침 칸에 붙여넣을 5줄 |
| 실습_요청문.txt | 전 섹션 | 교안의 요청문 모음 |
| 앞 차시 파일(없을 때만)/ | 업무 하나에 작업 공간 하나 ~ 한 줄로 시키고 | 하루담리빙_1주차_최종.xlsx와 하루담리빙_1주차_실적보고서.docx(예시). 앞 차시에서 받은 파일이 없는 학습자만 씀 |
