# 앱 연결해서 일하기 - 실습 파일

교안: [앱 연결해서 일하기](https://app.notion.com/p/402435fcbd9d81d1a0ffea538e2cddad)

## 학습자용 (수업 자료로 배포)

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| 실습메일_6통.txt | Gmail 연결해 메일 요약·회신 초안 받기 ① | 교안 [자료] 블록 그대로. 실습용 Gmail에서 내 주소로 보낼 메일 6통 |
| 실습_요청문.txt | 전 섹션 | 교안의 요청문 모음 (Gmail → Drive → 승인 카드 → 메모리) |
| Drive에 올릴 파일/ | Drive 파일 불러와 두 주 실적 비교하기 ① | Google Drive "하루담리빙_실적" 폴더에 올릴 4개. 1·2주차 최종 데이터(46건·51건)와 1·2주차 실적보고서. 앞 차시에서 직접 받은 파일이 있으면 그것을 써도 됨 |

## 강사용 (배포하지 않음)

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| 정답_메일_두주비교.xlsx | Gmail 연결해 메일 요약·회신 초안 받기 ~ Drive 파일 불러와 두 주 실적 비교하기 | 메일 분류·기한 정답, 메일에서 생길 수 있는 실수, 두 주 건수·합계 비교, 지점·상품 전체 증감률(바뀐 점 3가지 정답 포함) |

승인 카드와 메모리 실습은 화면에서 하는 실습이라 따로 파일이 없습니다.
