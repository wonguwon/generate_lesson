# [기본] ChatGPT 웹 기본 (Chat · Work) - 실습 파일

차시마다 폴더 하나이고, 폴더 안은 `학습자용`(수업 자료로 배포)과 `강사용`(정답·시연용, 배포하지 않음)으로 나뉩니다. 각 폴더의 README에 파일별 용도가 있습니다.

| 폴더 | 교안 | 학습자용 핵심 파일 |
| --- | --- | --- |
| 01_Work모드_첫작업 | Work 모드 첫 작업 | 협업툴_요금안내.txt (붙여넣기용 자료) |
| 02_파일_맡기고_결과파일_받기 | 파일 맡기고 결과 파일 받기 | 지점별 1주차 CSV 5개 (일부러 넣은 문제 포함) |
| 03_보고서_발표자료_만들기 | 보고서·발표자료 만들기 | 하루담리빙_1주차_최종.xlsx (46건, 2,054,000원) |
| 04_프로젝트로_묶어서_일하기 | 프로젝트로 묶어서 일하기 | 양식.docx, 용어정리.txt, 2주차_최종.xlsx (51건, 2,332,000원), 지침 5줄 |
| 05_앱_연결해서_일하기 | 앱 연결해서 일하기 | 실습메일_6통.txt, Drive에 올릴 파일 4개 |

모든 차시에 교안 요청문을 순서대로 모은 `실습_요청문.txt`가 있습니다. 텍스트와 CSV는 UTF-8(BOM)으로 저장해 Windows 메모장·엑셀에서 한글이 깨지지 않습니다.

## 다시 만들기

파일은 `_생성스크립트`에서 만듭니다. 하루담리빙 데이터와 정답 계산은 `haru_data.py` 하나에 있고, 차시 스크립트는 교안 정답 표의 숫자를 assert로 확인한 뒤에만 파일을 씁니다. 교안의 데이터나 정답을 바꾸면 이 모듈과 assert를 함께 고친 뒤 다시 실행합니다.

```bash
cd _생성스크립트
python -X utf8 make_01.py ..
python -X utf8 make_02.py ..
python -X utf8 make_03.py ..
python -X utf8 make_04.py ..
python -X utf8 make_05.py ..
```

필요한 패키지: openpyxl, python-docx
