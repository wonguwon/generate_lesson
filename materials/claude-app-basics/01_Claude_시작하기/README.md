# Claude 시작하기 - 실습 파일 (1교시)

교안: [1️⃣ Claude 시작하기](https://app.notion.com/p/d63435fcbd9d83df8bad014fafe0e68a)

이 교시의 실습은 모두 교안의 자료를 채팅창에 붙여넣는 방식이라, 압축해서 나눠 줄 실습 폴더(모아상사_실습_1)는 없습니다.
아래 파일은 붙여넣을 자료와 요청문을 한곳에 모은 것, 그리고 강사가 정답 대조와 시연에 쓸 파일입니다.

## 학습자용 (수업 자료로 배포)

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| 비품_구매내역.txt | 대화와 맥락 ①② · 메모리 ③ | 교안 [자료] 블록 그대로. 9행(9월 30일 ~ 10월 27일) |
| 주간회의_원문_2026-10-26.txt | 질문식 vs 위임식 ①② (권한 모드는 그 대화에서 이어감) | 교안 [회의 원문] 블록 그대로. 2교시 실습 폴더의 주간회의_2026-10-26.docx와 같은 내용 |
| 실습_요청문.txt | 전 섹션 | 교안의 요청문을 단계 순서대로 모은 것 |

텍스트는 UTF-8(BOM)으로 저장해 Windows 메모장에서 한글이 깨지지 않습니다.

## 강사용 (배포하지 않음)

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| 정답_1교시.xlsx | 대화와 맥락 · 메모리 · 질문식 vs 위임식 · 권한 모드 | 기준 넣은 요청 정답(7행, 157.0만원), 메모리 10월 보고서 정답(196.8만원), 기준 없이 나올 수 있는 결과, 할 일 표 4건, 확인할 곳과 실수 |
| 예시_회의록.docx, 예시_할일표.xlsx | 질문식 vs 위임식 ②④ | 위임식 결과가 잘 나왔을 때의 참고 모습. Claude가 파일을 만들지 못하는 상황에서 화면 설명용 |

## 정답 요약

| 확인할 것 | 정답 |
| --- | --- |
| 기준 넣은 요청 (10/5 ~ 10/23, 7행) | 영업팀 69.7 · 마케팅팀 43.9 · 경영지원팀 43.4 / 전체 157.0 (만원) |
| 메모리 10월 보고서 | 경영지원팀 83.2 · 영업팀 69.7 · 마케팅팀 43.9 / 전체 196.8 (만원) |
