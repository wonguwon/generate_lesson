# 주간업무 표 만들기

## 순서
1. 메모에서 할 일을 모두 찾는다.
2. 담당자를 아래 팀원 명단의 "이름 직급"으로 바꾼다.
3. 요약 3줄 → 주간업무 표 → 특이사항 → 다음 회의 순서로 쓴다.

## 주간업무 표
- 열: 담당자 / 할 일 / 마감 / 상태
- 표 아래에 "완료 ○건 · 진행 중 ○건 · 예정 ○건 / 전체 ○건" 한 줄

## 규칙
- 마감: 2026-11-06(금)처럼 연-월-일(요일)
- 상태: 완료(끝난 일) / 진행 중(하는 중) / 예정(아직 시작 전) 중 하나
- 행 순서: 마감이 빠른 순, 마감이 같으면 담당자 이름 가나다순
- 금액: 만원 단위, 나누어떨어지지 않으면 소수점 첫째 자리까지, 계산식을 함께
- 말투: 보고서체(~함, ~임)
- 메모에 없는 내용은 추가하지 않는다.

## 팀원 명단
- 김지현 팀장 (지현 팀장님, 팀장님)
- 박민수 대리 (민수)
- 이서연 주임 (서연)
- 최우진 사원 (우진)
