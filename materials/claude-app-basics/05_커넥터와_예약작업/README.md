## 학습자용 (수업 자료로 배포)

`학습자용\모아상사_실습_5` 폴더를 통째로 압축해 배포합니다(하위 폴더 2개, 파일 4개).

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| 모아상사_실습_5/Drive에_올릴_파일/주간회의록_2026-11-02.docx | Drive에 올려 둠(고르면 안 되는 지난 회의록) | 교안 📁 회의록 전문 그대로, 결정 2건 |
| 모아상사_실습_5/Drive에_올릴_파일/주간회의록_2026-11-09.docx | Drive에 올려 둠(고르면 안 되는 지난 회의록) | 교안 📁 회의록 전문 그대로, 결정 2건 |
| 모아상사_실습_5/Drive에_올릴_파일/주간회의록_2026-11-16.docx | 세 섹션 모두 | 교안 📁 회의록 전문 그대로, 결정 3건 · 보류 1건 |
| 모아상사_실습_5/나중에_올릴_파일/주간회의록_2026-11-23.docx | 예약 작업 "시간이 남으면" | 교안 📁 회의록 전문 그대로, 결정 2건 |
| 실습_요청문.txt | 전 섹션 | 교안의 요청문을 단계 순서대로 모은 것. 실습 폴더 밖에 둠 |

회의록 docx에는 교안 전문만 한 줄에 한 문단으로 들어 있습니다(제목·설명을 더하지 않아 "결정:"을 찾으면 11-16은 3곳).
