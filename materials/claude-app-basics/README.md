모든 교시에 교안 요청문을 단계 순서대로 모은 `학습자용\실습_요청문.txt`가 있습니다. 실습 폴더 밖에 두어 폴더 안 파일 개수가 교안과 같게 했습니다.

가상 회사 모아상사와 가상 거래처(모락오피스·가람테크렌탈·온새미사무기)만 쓰고, 문서에는 "(실습용 가상 회사)"를 적었습니다.

## 배포(압축)

압축은 직접 합니다. `학습자용` 안의 `모아상사_실습_N` 폴더를 **폴더째** 압축하면, 학습자가 풀었을 때 교안에 적힌 폴더 이름이 바로 나옵니다.
`실습_요청문.txt`는 압축에 넣지 않거나 폴더 밖에 따로 둡니다(폴더 안에 넣으면 2교시 "20개" 대조가 어긋남).
압축 전 파일 탐색기에서 `Thumbs.db`·`desktop.ini` 같은 숨김 파일이 생기지 않았는지 확인합니다.

## 다시 만들기

파일은 `_생성스크립트`에서 만듭니다. 모아상사 데이터와 정답 계산은 `moa_data.py` 하나에 있고, 교시 스크립트는 교안 정답 표의 숫자를 assert로 확인한 뒤에만 그 교시의 `학습자용`·`강사용`을 지우고 다시 씁니다.
교안의 데이터나 정답을 바꾸면 이 모듈과 assert를 함께 고친 뒤 다시 실행합니다.

```bash
cd _생성스크립트
py -3.14 -X utf8 make_01.py ..
py -3.14 -X utf8 make_02.py ..
py -3.14 -X utf8 make_03.py ..
py -3.14 -X utf8 make_04.py ..
py -3.14 -X utf8 make_05.py ..
py -3.14 -X utf8 make_readme.py ..
py -3.14 -X utf8 점검.py ..
```

`점검.py`는 다섯 스크립트를 임시 폴더에 다시 실행해 지금 파일과 내용이 같은지, 실습 폴더 파일 개수가 교안 명세와 같은지, 빈 폴더·zip이 없는지 확인합니다. 마지막 줄이 "모두 일치"면 정상입니다.

필요한 것: Python 3.10 이상(위 명령은 이 PC의 Python 3.14 기준), Windows 맑은 고딕 글꼴(`C:\Windows\Fonts\malgun.ttf`, PDF·jpg 한글용)

```bash
py -3.14 -m pip install openpyxl python-docx python-pptx reportlab pillow pypdf
```
