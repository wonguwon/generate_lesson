[실습 1-④ 규칙 추가 (같은 세션)]
CLAUDE.md 맨 아래에 아래 두 항목을 그대로 더해 줘. 다른 줄은 바꾸지 마.

## 작업 규칙
- '원본' 폴더의 파일은 읽기만 한다. 고치거나 옮기거나 지우지 않는다.
- 결과 파일은 '출력' 폴더에만 쓴다.
- 새 결과 파일 이름은 YYYY-MM_내용 (예: 2026-09_거래처별합계.md). '주문_정리본.csv'·'처리기록.md'는 이름 그대로 이어 쓴다.
- 금액은 원 단위, 천 단위 쉼표 (예: 1,234,500원). %는 소수 첫째 자리.

## 월간 주문 정리 (새 달 주문 CSV가 '원본/월별주문'에 들어오면)
1. 복사본 'YYYY-MM_주문.csv'를 '출력/월별주문'에 만든다.
2. '출력/주문_정리본.csv'에 그 달 행을 더한다. 주문일은 YYYY-MM-DD, 주문번호가 같으면 첫 행만, 수량이 빈 행만 뺀다. 비고만 빈 행은 둔다.
3. '출력/처리기록.md'에 그 달의 합치기 전 행 수와 뺀 행·이유를 더한다.
4. Claude Docs로 'YYYY년 M월 월간 주문 보고서'를 만든다. 항목: 1) 요약(주문 건수, 판매 합계, 전월 대비 금액·%) 2) 7월부터 월별 추이 표 3) 거래처 상위 3곳 표(거래처/담당자/판매 금액/그 달 합계 대비 비중)와 3곳 합 비중 한 줄 4) 그 달 수량이 비어 빠진 주문번호
5. Claude Slides로 5장: 표지 / 핵심 숫자 / 월별 추이 막대그래프(막대 위 판매 합계) / 상위 3곳과 비중 / 확인이 필요한 주문. 숫자는 Docs 보고서 숫자를 그대로 쓴다.
