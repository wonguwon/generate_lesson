[2교시 실습 요청문] 교안 순서대로 복사해 씁니다.

[실습 1-② 계획 요청 (모드: 계획)]
'원본/월별주문' 폴더의 7·8·9월 주문 CSV를 정리하려고 해. 실행하지 말고 계획부터 보여 줘.
- 원본 폴더는 읽기만 해. 고치거나 옮기거나 지우지 마.
- 파일 이름 규칙: YYYY-MM_주문.csv (예: 2026-07_주문.csv). 새 이름의 복사본을 '출력/월별주문'에 만들어.
- 계획에 이름 변경 표(지금 이름 → 바꿀 이름)를 넣어 줘.
- 세 달을 하나로 합쳐 '출력/주문_정리본.csv'로 저장. 주문일은 YYYY-MM-DD로 통일하고, 중복 행과 빈칸이 있는 행은 정리해.
- 무엇을 몇 행 뺐는지 '출력/처리기록.md'에 남겨.
- 프로그램은 설치하지 말고 지금 PC에 있는 방법으로 해.

[실습 1-④ 계획 고치기]
계획을 이렇게 고쳐 줘.
- 이름 변경: 주문서_양식.csv는 주문 데이터가 아니니 이름도 바꾸지 말고 정리에서도 빼.
- 처리 기준: 중복은 주문번호가 같으면 첫 행만 남기고, 빈칸은 수량이 빈 행만 빼. 비고만 빈 행은 그대로 둬.
고친 계획을 다시 보여 줘.

[실습 2-① Claude Docs 보고서]
'출력/주문_정리본.csv'를 읽고 2026년 9월 월간 주문 보고서를 Claude Docs로 만들어 줘.
- 숫자는 정리본에서 직접 계산해. 금액은 원 단위, 천 단위 쉼표. %는 소수 첫째 자리.
- 항목 4개
  1. 9월 요약: 주문 건수, 판매 합계, 8월 대비 증감(금액, %)을 담은 짧은 글
  2. 7~9월 월별 추이: 월 / 주문 건수 / 판매 합계 표와 설명 한두 줄
  3. 9월 거래처 상위 3곳: 거래처 / 담당자 / 판매 금액 / 9월 합계 대비 비중 표, 아래에 3곳 합 비중 한 줄
  4. 확인이 필요한 주문: '출력/처리기록.md'에서 수량이 비어 빠진 주문번호
- 원본 폴더는 읽기만 해.

[실습 2-③ 문장·흐름 검토]
방금 만든 보고서의 문장을 검토해 줘. 고치지는 마.
- 표 열: 항목 / 문장 / 근거(정리본·처리기록의 어느 숫자) / 판정
- 판정은 셋 중 하나: 자료에서 나온 사실 / 자료에 없는 해석·추측 / 숫자와 다른 표현
- 마지막에 흐름 점검: 항목 순서가 요청과 같은지, 1번 요약의 숫자와 2·3번 표의 숫자가 같은지

[실습 2-④ 근거 없는 문장 고치기]
③에서 '자료에 없는 해석·추측'과 '숫자와 다른 표현'으로 판정한 문장만 고쳐 줘.
- 해석·추측 문장은 지워.
- 숫자와 다른 표현은 숫자로 바꿔 (예: '큰 폭 증가' → '+14.9% 증가').
- 나머지 문장과 숫자는 한 글자도 바꾸지 마.

[실습 3-① 개요 요청]
9월 주문 요약 발표자료를 만들려고 해. 아직 발표자료는 만들지 말고 장별 개요부터 채팅에 보여 줘.
- 영업관리팀 주간회의용 5장
- 장마다: 제목 / 넣을 내용 / 넣을 숫자
- 1장 표지 / 2장 9월 핵심 숫자(주문 건수·판매 합계·8월 대비) / 3장 7~9월 월별 추이 / 4장 거래처 상위 3곳과 비중 / 5장 확인이 필요한 주문
- 숫자는 새로 계산하지 말고 앞에서 검토한 Docs 보고서의 숫자를 그대로 써.
- 금액은 원 단위, 천 단위 쉼표.

[실습 3-② 개요 고쳐 확정하기]
개요를 이렇게 고쳐 줘. 아직 발표자료는 만들지 마.
- 5장으로 맞춰.
- 3장: 월별 추이를 막대그래프로. 막대 위에 월별 판매 합계, 그래프 아래에 한 줄 '9월이 세 달 중 가장 많음'
- 자료에 없는 원인·전망 문장은 넣지 마.
고친 개요를 다시 보여 줘.

[실습 3-③ /slides로 만들기]
/slides 위에서 확정한 개요 그대로 5장으로 만들어 줘. 내용과 숫자는 바꾸지 마.
