## 3교시 파일을 Drive에 올리기

교안은 학습자가 링크를 열어 Google 스프레드시트·문서의 사본을 만드는 흐름입니다. xlsx·docx를 그대로 공유하면 Office 파일 상태로 남으므로 변환본을 공유합니다.

1. `Drive에_올릴_파일`의 파일 3개를 Drive에 올립니다.
2. 각 파일을 연 뒤 파일 › Google 스프레드시트로 저장(예산 문서는 Google 문서로 저장)을 누릅니다.
3. 변환본의 공유를 링크가 있는 모든 사용자 · 뷰어로 바꿉니다.
4. 변환본 링크 3개를 교안에 넣습니다. 링크 끝의 `/edit...`를 `/copy`로 바꾸면 사본 만들기 화면으로 바로 열립니다.

## 다시 만들기

`haneul_data.py`에 데이터와 정답 계산이 있고, 교시 스크립트는 교안 정답을 assert로 확인한 뒤에만 그 교시 폴더를 지우고 다시 씁니다. 교안을 바꾸면 이 모듈과 assert를 함께 고칩니다.

```bash
cd _생성스크립트
python -X utf8 make_03.py ..
python -X utf8 make_04.py ..
python -X utf8 make_05.py ..
python -X utf8 make_readme.py ..
python -X utf8 점검.py ..
```

필요한 패키지: openpyxl, python-docx
