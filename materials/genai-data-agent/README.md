# 생성형 AI 기반 데이터 분석 - 실습 데이터

ChatGPT 채팅·작업 모드로 데이터를 분석하는 10차시 과정의 실습 데이터입니다. 대학가 배달 주문을 지어낸 **가상 데이터**이고, 가게 이름·고객 번호·리뷰는 모두 지어낸 것입니다. 기간은 2025년 1학기(2025-03-03 ~ 06-22, 16주)이며 가상 중간고사(04-21 ~ 25)와 기말고사(06-16 ~ 20)가 들어 있습니다.

교안과 촬영 전 확인할 것은 노션 [과정 설계 페이지](https://app.notion.com/p/4e389cf6e287433583145b0c42b51aba)에 있습니다.

## 파일

`data/`의 CSV는 모두 UTF-8(BOM 있음)이라 엑셀에서 바로 열어도 한글이 깨지지 않습니다. 열 18개가 모든 파일에서 같습니다.

| 파일 | 기간 | 행 수 | 설명 |
| --- | --- | --- | --- |
| `data/orders_2025_w01-12.csv` | 03-03 ~ 05-25(1~12주) | 4,526 | 기본 파일. 빈칸·중복·형식 불일치·이상치·계산 불일치가 섞여 있음 |
| `data/orders_2025_w13.csv` | 05-26 ~ 06-01 | 375 | 맨 앞 7행은 기본 파일 마지막 날 주문이 다시 들어온 것 |
| `data/orders_2025_w14.csv` | 06-02 ~ 06-08 | 369 | 처음 보는 표기 두 가지(category `떡볶이`, payment_method `페이`) |
| `data/orders_2025_w15.csv` | 06-09 ~ 06-15 | 371 | 새 문제 없음 |
| `data/orders_2025_w16.csv` | 06-16 ~ 06-22 | 419 | 가상 기말고사 주간. 야식·치킨·카페디저트 주문 약 1.4배 |

주차 파일에도 기본 파일과 같은 종류의 지저분함이 작은 비율로 들어 있어, 같은 정제 규칙이 그대로 통하는지 확인할 수 있습니다.

강사용(배포하지 않음):

| 파일 | 설명 |
| --- | --- |
| `_tools/data_facts.md` | 교안 정답 숫자. 원본·정제 뒤 행 수, 품질 점검표, 정제 규칙, 카테고리·지역별 매출, 시간대·요일, 시험 기간 배율, 배달 시간-평점 상관, 리뷰 수와 감성·주제 비율, 주차별 누적, 14주차 새 표기 위치 |

## 구글 드라이브 실습 폴더

교안의 폴더 구조입니다(6차시까지는 내 PC `데이터분석_실습/` 안의 `data/`·`output/`을 씁니다).

```
배달주문_실습/
├─ 수신/        주차 파일을 넣는 곳
├─ 기준/        데이터 사전·리뷰 기준표·배치 스케치(8차시에 올림)
├─ 누적/        정제한 누적 파일(시작 파일은 사람이, orders_2025_clean.csv는 에이전트가)
├─ 결과/        결과 시트·대시보드(에이전트가 만듦)
└─ 처리기록.md   어느 주차까지 붙였는지(7차시 실습 중 에이전트가 처음 만듦)
```

`수신` 폴더에는 한꺼번에 넣지 않고 차시마다 한 주차씩 넣습니다. 미리 넣어 두면 에이전트가 다음 주차까지 가져와 버립니다.

1. 7차시 시작 전: `orders_2025_w13.csv`
2. 8차시 시작 전: `orders_2025_w14.csv`
3. 9차시 시작 전: `orders_2025_w15.csv`
4. 10차시 실습 3 도중: `orders_2025_w16.csv`(예약 실행이 새 파일을 집어 가는지 보려고 실습 중에 넣음)

`처리기록.md`는 자료로 주지 않습니다. 7차시 실습 중 첫 누적 때 에이전트가 만들고, 이후 차시는 그 파일을 읽고 갱신합니다.

## 다시 만들기

제작 환경은 `_tools/.venv`(Python 3.14, pandas 3.1.1, numpy 2.5.4)입니다. `.venv`는 git에 올라가지 않으니 없으면 새로 만듭니다.

```bash
py -3 -m venv _tools/.venv
_tools/.venv/Scripts/python.exe -m pip install -r _tools/requirements.txt
_tools/.venv/Scripts/python.exe _tools/make_data.py
_tools/.venv/Scripts/python.exe _tools/check_data.py
```

- `make_data.py`는 시드가 고정돼 있어 몇 번을 실행해도 같은 파일이 나옵니다(같은 패키지 버전 기준).
- `check_data.py`는 CSV를 글자 그대로 다시 읽어 문제 개수와 패턴을 검사하고 `_tools/data_facts.md`를 새로 씁니다. 실패한 항목이 있으면 표에 '실패'로 적고 종료 코드 1로 끝납니다.
- 데이터를 바꾸면 `data_facts.md`의 숫자도 바뀌므로, 교안에 넣은 정답 숫자를 다시 맞춰야 합니다.
