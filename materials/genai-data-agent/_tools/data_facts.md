# 실습 데이터 정답표 (data_facts)

`make_data.py`로 만든 가상 데이터의 실제 값이다. `check_data.py`가 CSV를 읽어 자동으로 쓴 파일이므로 손으로 고치지 않는다. 교안·대본의 정답 숫자는 여기서 가져다 쓴다.

- 다시 만들기: `_tools/.venv/Scripts/python.exe _tools/make_data.py` → `_tools/.venv/Scripts/python.exe _tools/check_data.py`
- 행 번호: 엑셀 행 번호 = pandas index + 2(1행은 머리글). 아래 '엑셀 N행'은 원본 CSV를 엑셀로 열었을 때의 행이다.
- 금액 단위는 원. 비율은 소수 첫째 자리 반올림.
- 리뷰 감성·주제·함정 정답은 `_tools/answer_key.csv`(배포하지 않음). 감성·주제 비율은 이 정답표 기준이다.

## 8. 설계안과 다른 점

- delivery_minutes 빈칸: 설계는 '약 2%(취소 주문은 정상, 나머지는 기록 누락)'. 취소가 약 4%라 취소를 모두 빈칸으로 두면 2%를 넘는다. 그래서 취소 주문은 모두 빈칸, 그 밖에 배달된 주문의 약 2%를 기록 누락으로 비웠다. 기본 파일 빈칸 합계 281행(6.2%).
- 16주차 행 수: 설계 약 450행. 시험 기간(06-16~20, 5일) 세 카테고리만 1.4배로 늘리면 419행이 된다. 맞추려고 다른 증가를 더 넣지 않았다.
- 정제 규칙 중 설계 페이지에 없는 것(위 규칙 표의 '자료 기준')은 이 자료에서 정한 기준이다. 교안에서 다른 규칙을 쓰면 정제 뒤 숫자가 달라진다.
- 평점은 리뷰를 쓴 주문에만 있다(평점만 있고 글이 없는 주문은 없음).
- `처리기록.md`는 설계 파일 표에 있지만 이번 제작 범위 밖이라 만들지 않았다. 7차시 실습 1이 처리 기록을 읽게 하므로 빈 시작 파일을 둘지 교안에서 정해야 한다.
- 9차시 실습 1(누적 리뷰 전체 분류) 시점에는 14주차까지만 누적돼 리뷰가 1,312개다. 설계의 '약 1,400개'는 15주차까지 누적(1,405개) 기준이라 실습 1 시점과 맞지 않는다.
