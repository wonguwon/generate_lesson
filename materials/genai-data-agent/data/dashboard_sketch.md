# 배달 주문 대시보드 배치 스케치

숫자는 이 문서에 적지 않는다. 모든 숫자는 `analysis_summary.xlsx`에서 읽어 넣는다.

## 화면 위쪽

- 제목: 대학가 배달 주문 대시보드
- 부제: 기준 시트에 적힌 기간과 고른 주문을 한 줄로

## 1줄 - 지표 카드 4개 (왼쪽부터)

| 카드 | 읽을 시트 | 읽을 칸 | 표시 |
| --- | --- | --- | --- |
| 매출 | 핵심지표 | 지표가 '매출'인 행의 값 | 원 단위, 쉼표 |
| 완료 주문 수 | 핵심지표 | 지표가 '완료 주문 수'인 행의 값 | 건 |
| 건당 평균 금액 | 핵심지표 | 지표가 '건당 평균 금액'인 행의 값 | 원 단위, 쉼표 |
| 평균 평점 | 핵심지표 | 지표가 '평균 평점'인 행의 값 | 소수 둘째 자리 |

## 2줄 - 차트 2개 (왼쪽 넓게, 오른쪽 좁게)

차트 1
- 제목(질문): 주문은 주마다 어떻게 달라지나?
- 읽을 시트: 주차별
- 가로: 주차 / 세로: 완료 주문 수
- 모양: 선 차트, 점마다 숫자 표시
- 덧붙임: 중간고사가 든 주차에 '중간고사' 표시(기준은 시작일 2025-04-21)

차트 2
- 제목(질문): 어느 요일, 어느 시간에 주문이 몰리나?
- 읽을 시트: 시간대x요일
- 행: 시간대(시트 순서 그대로, 10시부터 다음 날 1시까지) / 열: 월~일
- 모양: 색 칸 표(숫자가 클수록 진한 색, 칸 안에 숫자)

## 3줄 - 차트 1개 (가로 전체)

차트 3
- 제목(질문): 어느 주제에서 불만이 많나?
- 읽을 시트: 리뷰분류
- 가로: 주제 6가지 / 세로: 합계 열
- 모양: 막대 차트, 막대마다 숫자 표시
