# 데이터 사전: 대학가 배달 주문(가상)

어느 대학교 주변 배달 주문을 지어낸 가상 데이터다. 가게 이름, 고객 번호, 리뷰는 모두 지어낸 것이고 실제 가게와 관계가 없다.

- 기간: 2025년 1학기, 2025-03-03(월) ~ 2025-06-22(일), 16주
- 한 행 = 주문 한 건
- 파일: `orders_2025_w01-12.csv`(1~12주), 그 뒤로 한 주에 파일 하나씩 `orders_2025_w13.csv` ~ `orders_2025_w16.csv`
- 모든 파일의 열 구성이 같다(18열). 주문 번호는 파일이 바뀌어도 이어진다.

## 열

| 열 이름 | 뜻 | 단위·형식 | 값 범위·예 |
| --- | --- | --- | --- |
| order_id | 주문 번호. 주문 한 건에 하나 | 글자 | `O000001`부터 차례로 |
| order_datetime | 주문한 날짜와 시각 | `YYYY-MM-DD HH:MM`(24시간제) | `2025-03-05 18:32`. 영업은 10시 ~ 다음 날 새벽 2시 |
| store_id | 가게 번호 | 글자 | `S01` ~ `S40` |
| store_name | 가게 이름(가상) | 글자 | 정문치킨, 후문떡볶이 등. 가게 하나는 category 하나에 속함 |
| category | 음식 종류 | 정해진 7가지 | `치킨` `분식` `한식` `중식` `피자` `카페디저트` `야식` |
| menu | 주문한 대표 메뉴 | 글자 | 후라이드, 떡볶이 세트, 아메리카노 등 |
| quantity | 수량 | 개 | 1 ~ 6 |
| unit_price | 메뉴 한 개 값 | 원 | 3,000 ~ 32,000 |
| delivery_fee | 배달비 | 원 | 0 ~ 4,000 |
| discount | 할인 금액 | 원 | 0 ~ 5,000 |
| total_amount | 결제 금액 | 원(숫자만) | 수량 × 단가 + 배달비 − 할인. 환불 주문은 같은 금액을 음수로 적음 |
| payment_method | 결제 수단 | 정해진 3가지 | `카드` `간편결제` `현금` |
| delivery_area | 배달 받은 곳 | 정해진 5가지 | `기숙사` `정문` `후문` `쪽문` `원룸촌` |
| customer_id | 고객 번호(가상) | 글자 | `C0001` ~ `C2500` |
| delivery_minutes | 주문부터 도착까지 걸린 시간 | 분(정수) | 보통 15 ~ 80. 취소 주문은 배달이 없어 빈칸 |
| status | 주문 상태 | 정해진 3가지 | `완료` `취소` `환불` |
| rating | 평점 | 1 ~ 5(정수) | 리뷰를 남긴 주문에만 있음. 리뷰가 없으면 빈칸 |
| review_text | 리뷰 글 | 글자 | 리뷰를 남긴 주문에만 있음. 리뷰가 없으면 빈칸 |

## 알아 둘 점

- 매출은 `완료` 주문의 total_amount를 더한 값이다. `취소`는 결제가 되지 않은 주문, `환불`은 배달 뒤 돈을 돌려준 주문이다.
- rating·review_text가 빈칸인 것은 손님이 리뷰를 쓰지 않았다는 뜻이다. 대부분의 주문이 이렇다.
