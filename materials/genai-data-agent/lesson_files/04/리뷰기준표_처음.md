[감성] 하나만 고름
- 긍정: 만족, 칭찬
- 부정: 불만, 실망
- 중립: 보통, 무난, 나쁘진 않지만 또 시킬 정도는 아님, 바라는 점만 적음

[주제] 하나만 고름
- 맛: 맛, 간, 식감, 냄새
- 배달: 배달 시간, 기사님, 도착 연락
- 양: 양, 건더기, 크기
- 포장: 용기, 새는 것, 빠진 수저·소스
- 가격: 가격, 배달비, 가성비
- 기타: 가게 응대, 요청사항, 주문 누락, 보통이라는 말만 있는 리뷰

[예시]
면발이 탱글하고 국물이 칼칼해요. → 긍정 / 맛
주문하고 1시간이 지나서야 왔어요. → 부정 / 배달
1인분인데 배부르게 먹고도 남았어요. → 긍정 / 양
국물이 새서 봉투가 다 젖었어요. → 부정 / 포장
배달비가 메뉴값만큼 나와요. → 부정 / 가격
사장님이 메뉴 고르는 걸 친절하게 도와주셨어요. → 긍정 / 기타
못 먹을 정도는 아닌데 굳이 또 시키진 않을 것 같아요. → 중립 / 맛
