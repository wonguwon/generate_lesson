배달 주문 주간 갱신과 대시보드 다시 게시를 해 줘. 이 요청은 예약으로 사람이 없을 때 실행돼. 중간에 묻지 말고, 승인 없이 할 수 없는 일이 있으면 그 자리에서 멈추고 실행 보고에 적어.

[1. 갱신]
- weekly-order-update 스킬로 이번 주 갱신해 줘. 스킬의 절차와 멈추고 보고하기를 그대로 따라.

[2. 다시 게시] 1번 결과로 정해.
- 새 파일 없음: 사이트를 다시 게시하지 마.
- 멈추고 보고함: 사이트를 다시 게시하지 마.
- 완료 보고까지 감: 배달주문_실습/결과/index.html을 배달주문 대시보드 사이트의 새 버전으로 그대로 배포해. 화면과 숫자는 고치지 말고, 공유 범위는 지금 그대로 둬.

[3. 실행 보고] 맨 위에 실행 결과 한 줄, 그 아래 표로
- 실행 결과: 완료 / 새 파일 없음 / 멈춤 가운데 하나
- 가져온 파일: 파일 이름, 원본 행, 정제 뒤 행, 새로 붙인 행, 붙인 뒤 누적 행
- 숫자: 핵심지표 시트의 값, 주차별 시트의 마지막 두 줄, 시험기간 시트의 배율
- 리뷰: 새로 분류한 리뷰 수, 검토 일치율, 불일치 수
- 사이트: 다시 게시했는지, 사이트 주소
- 멈췄거나 게시하지 않았으면: 그 이유와 사람이 할 일
