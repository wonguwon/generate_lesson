# 리뷰 분류 기준표

리뷰 표본 200개를 분류하고 1~20번을 검수해 고친 기준표. 감성과 주제를 하나씩 고른다.

[감성] 하나만 고름
- 긍정: 만족, 칭찬
- 부정: 불만, 실망
- 중립: 보통, 무난, 나쁘진 않지만 또 시킬 정도는 아님, 바라는 점만 적음

[주제] 하나만 고름
- 맛: 맛, 간, 식감, 냄새
- 배달: 배달 시간, 기사님, 도착 연락
- 양: 양, 건더기, 크기
- 포장: 용기, 새는 것, 빠진 수저·소스
- 가격: 가격, 배달비, 가성비
- 기타: 가게 응대, 요청사항, 주문 누락, 보통이라는 말만 있는 리뷰

[예시]
면발이 탱글하고 국물이 칼칼해요. → 긍정 / 맛
주문하고 1시간이 지나서야 왔어요. → 부정 / 배달
1인분인데 배부르게 먹고도 남았어요. → 긍정 / 양
국물이 새서 봉투가 다 젖었어요. → 부정 / 포장
배달비가 메뉴값만큼 나와요. → 부정 / 가격
사장님이 메뉴 고르는 걸 친절하게 도와주셨어요. → 긍정 / 기타
못 먹을 정도는 아닌데 굳이 또 시키진 않을 것 같아요. → 중립 / 맛

[더한 규칙]
1. 주제가 둘 이상이면 먼저 말한 것 하나. "과제하다가 시켰어요" 같은 상황 설명과 "또 시킬게요" 같은 인사는 빼고 봄
   예: 국물이 진해요. 포장도 깔끔해요. → 긍정 / 맛
2. 한 문장 안에서 "~는데", "~지만" 앞뒤가 반대면 뒤의 말이 결론
   예: 늦을 줄 알았는데 20분 만에 왔어요. → 긍정 / 배달
3. 따로 덧붙인 짧은 반대 말("다만 ~", "~은 괜찮았어요")은 감성에 넣지 않음
   예: 양이 정말 많아요. 다만 배달은 좀 늦었어요. → 긍정 / 양
4. 음식이 식거나 미지근하게 도착한 것은 배달
   예: 도착은 빨랐지만 피자가 차갑게 식어 있었어요. → 부정 / 배달
5. 무엇에 대한 말인지 없이 좋다, 싫다만 쓴 짧은 리뷰는 맛
   예: 그닥이에요. → 부정 / 맛
