# 웹 생성형 AI와 LLM API - 실습 파일 (1차시)

교안: [1️⃣ API1 : 웹 생성형 AI와 LLM API](https://app.notion.com/p/7b6435fcbd9d838e91de0130f00c63b5)

이 차시 실습은 모두 Gemini 웹과 Google AI Studio 화면에서 합니다. Get code도 열어 보기만 하고 실행은 2차시에 하므로, 이 차시에는 파이썬 코드 파일이 없습니다.
화면에 붙여넣을 요청문만 모았습니다.

## 파일

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| 실습_요청문.txt | 실습 1 ①② · 실습 3 ①② | 교안의 요청문 블록 세 개 그대로. 실습 1 질문, 실습 3 한국어 안내문·영어 안내문. 메모장에서 한글이 깨지지 않게 UTF-8(BOM)으로 저장 |

실습 2(API 키 발급)는 화면 조작만 있어 파일이 없습니다. 강사 화면의 키는 촬영 중 가리고 촬영 후 삭제합니다.

## 정답 요약

교안의 정답 표를 옮긴 것입니다. 실제 화면으로 아직 대조하지 않은 예측입니다.

| 확인할 곳 | 정답 |
| --- | --- |
| 실습 1 · Gemini 웹 화면 | temperature를 정하는 칸이 화면에 없음 |
| 실습 1 · AI Studio 설정 패널 | 모델 선택, 시스템 지시, temperature 칸이 있음 |
| 실습 1 · 두 답 | 내용은 비슷하고 문장은 다를 수 있음 |
| 실습 1 · Get code 코드 | 모델 이름이 적힌 줄, 내 질문 문장이 들어간 줄이 있음. 호출 줄은 client.interactions.create 모양 |
| 실습 2 · 키 목록 | 방금 만든 키가 한 줄 더 보임 |
| 실습 2 · 프로젝트 칸 | ②에서 고른 프로젝트 이름 |
| 실습 2 · 등급 칸 | 무료 등급 표시 |
| 실습 2 · 보관한 곳 | 나만 보는 곳에 키 전체가 있음 |
| 실습 3 · 토큰 수 | 글자 수는 한국어가 훨씬 적지만, 토큰 수는 비슷하거나 한국어가 더 많은 경우가 많음. 정확한 수는 모델마다 다름 |
| 실습 3 · 한도 화면 | 모델마다 RPM·TPM·RPD 칸이 있음. 수치는 사람마다 다를 수 있음 |
