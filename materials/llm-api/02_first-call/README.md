# 개발 환경과 첫 API 호출 - 실습 파일 (2차시)

교안: [2️⃣ API2 : 개발 환경과 첫 API 호출](https://app.notion.com/p/d8e435fcbd9d82b894a101018abb56f0)

학습자는 교안을 보며 `llm-api/02_first-call/`에 파일을 직접 만들고 코드를 입력합니다. 이 폴더의 파일은 그 완성 상태입니다. 시작용 뼈대나 데이터 파일은 없습니다.
실습 2에서 만드는 `.env.example`·`.gitignore`는 이 과정 폴더(`llm-api/`) 맨 위의 공용 파일을 씁니다. `.env`는 배포하지 않으며, 각자 `GEMINI_API_KEY=내_키` 한 줄로 만듭니다.

## 파일

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| 실습1_버전확인.py | 가상환경과 google-genai 설치 · 실습 1 ④ | 파이썬 버전, google-genai 버전, 실행 중인 환경 경로 출력 |
| 실습2_키확인.py | 환경 변수와 .env 파일 · 실습 2 ③ | .env의 `GEMINI_API_KEY`를 읽어 키 값 대신 글자 수만 출력 |
| 실습3_첫호출.py | interactions.create 첫 호출 · 실습 3 ② | Get code 코드를 고친 완성 코드. 수강 정정 기간 질문 하나를 보내고 답 출력 |
| 실습4_토큰확인.py | 응답 객체와 토큰 사용량 · 실습 4 ② | 짧은 질문·긴 질문의 답과 입력·출력·생각·합계 토큰 출력 |

- 교안의 각 코드 블록과 같습니다(변수 이름, 질문 문장, `MODEL = "gemini-3.8-flash"`, print 줄).

## 실행

`llm-api` 폴더에서 실행합니다(VS Code 실행 버튼도 같은 위치에서 실행). `load_dotenv()`가 `llm-api/.env`를 읽습니다.

```bash
python 02_first-call/실습3_첫호출.py
```

다른 파일도 `python 02_first-call/파일이름.py`로 실행합니다.

### 단계별로 바꾸는 줄

이 폴더의 파일은 각 실습의 완성 코드 블록 상태입니다. 아래 단계는 시연할 때 직접 고칩니다.

| 단계 | 파일 | 바꾸는 곳 |
| --- | --- | --- |
| 실습 3 ④ | 실습3_첫호출.py | `input` 문장만 `대학 도서관에서 처음 책을 빌리는 방법을 세 단계로 알려 줘.`로 바꿔 다시 실행 |
| 실습 4 ① | 실습3_첫호출.py | 맨 아래에 `print(interaction.id)`, `print(interaction.usage)` 두 줄 추가 |

## 정답 요약

교안의 정답 표를 옮긴 것입니다. 실제 키로 아직 실행하지 않은 예측입니다.

| 확인할 곳 | 정답 |
| --- | --- |
| 실습 1 · 터미널 줄 앞 | (.venv) |
| 실습 1 · 파이썬 버전 | 3.11 이상 |
| 실습 1 · google-genai 버전 | 숫자가 출력됨. 촬영 시점 최신 버전이라 강사 화면과 다를 수 있음 (작성 시점 2.34.0) |
| 실습 1 · 실행 중인 환경 | 경로 끝이 `.venv` |
| 실습 2 · 터미널 출력 | `키를 불러왔습니다. 글자 수:` 뒤에 숫자 |
| 실습 2 · 출력 내용 | 키 문자열은 어디에도 보이지 않음 |
| 실습 2 · .gitignore | `.env` 줄이 있음 |
| 실습 2 · .env.example | `GEMINI_API_KEY=` 뒤가 비어 있음 |
| 실습 3 · ③의 답 | 수강 정정 기간이 과목을 바꾸거나 취소할 수 있는 기간이라는 설명, 두 문장 안팎 |
| 실습 3 · ④의 답 | 도서관에서 책을 빌리는 단계 세 가지 |
| 실습 3 · 코드 | 키 문자열이 어디에도 없음, 호출에 `model=MODEL` |
| 실습 4 · 입력 토큰 | 긴 질문이 짧은 질문보다 많음 |
| 실습 4 · 출력 토큰 | 설명을 쓴 짧은 질문이 '확인'만 쓴 긴 질문보다 많은 경우가 많음 |
| 실습 4 · 합계 | 입력 + 출력 + 생각과 같은 경우가 많음 |
| 실습 4 · 긴 질문의 입력 토큰 | 1차시에 AI Studio에서 본 한국어 수와 비슷함. 정확히 같지 않을 수 있음 |
