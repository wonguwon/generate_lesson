# 모델 선택과 생성 설정 - 실습 파일 (3차시)

교안: [3️⃣ API3 : 모델 선택과 생성 설정](https://app.notion.com/p/7b2435fcbd9d82f48c5b817154fb9691)

학습자는 교안을 보며 `llm-api/03_model-config/`에 파일을 직접 만들고 코드를 입력합니다. 이 폴더의 파일은 그 완성 상태입니다. 시작용 뼈대나 데이터 파일은 없습니다.

## 파일

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| 실습1_모델비교.py | 모델 등급 · 실습 1 | 같은 질문을 `gemini-3.8-flash`와 `gemini-3.5-flash-lite`에 보내 시간·답·토큰 출력 |
| 실습2_시스템지시.py | 시스템 지시 · 실습 2 | 학과 안내 도우미 `SYSTEM_INSTRUCTION`, 질문 세 개를 지시 없이/있이 비교 (③의 규칙 흔들기 질문까지 넣은 상태) |
| 실습3_생성설정.py | 생성 설정 · 실습 3 ① | 시간표 문제를 `thinking_level` low·high로 보내 시간·상태·토큰 출력 |
| 실습4_퓨샷분류.py | 퓨샷 프롬프트 · 실습 4 | 제로샷 1건과 퓨샷 분류 7건 (③의 계절학기 문의까지 넣은 상태) |

- 교안의 각 코드 블록과 같습니다. 실습 2·4는 ③에서 목록에 더하는 항목을 넣은 마지막 상태입니다.
- 4·5차시는 실습2의 `SYSTEM_INSTRUCTION`을 그대로 복사해 씁니다.

## 실행

`llm-api` 폴더에서 실행합니다(VS Code 실행 버튼도 같은 위치에서 실행).

```bash
python 03_model-config/실습1_모델비교.py
```

다른 파일도 `python 03_model-config/파일이름.py`로 실행합니다.

### 단계별로 바꾸는 줄

| 단계 | 파일 | 바꾸는 곳 |
| --- | --- | --- |
| 실습 1 ③ | 실습1_모델비교.py | 맨 아래에 `ask("gemini-3.1-pro-preview")` 추가 → 오류 확인 후 그 줄 지우기 (교안 지시대로 파일에는 없음) |
| 실습 2 ③ | 실습2_시스템지시.py | ①②만 시연하려면 `questions`의 세 번째 문장을 지우고 실행 |
| 실습 3 ③ | 실습3_생성설정.py | 맨 아래 `ask` 두 줄을 `ask("신입생에게 학과 생활 팁을 다섯 가지 자세히 알려 줘.", "low", max_tokens=100)` 한 줄로 바꾸기 |
| 실습 4 ③ | 실습4_퓨샷분류.py | ①②만 시연하려면 `questions`의 마지막 문의(계절학기)를 지우고 실행 |

## 정답 요약

교안의 정답 표를 옮긴 것입니다. 실제 키로 아직 실행하지 않은 예측입니다.

| 확인할 곳 | 정답 |
| --- | --- |
| 실습 1 · 응답 시간 | Flash-Lite가 더 짧은 경우가 많음. 실행마다 달라짐 |
| 실습 1 · 생각 토큰 | Flash는 숫자, Flash-Lite는 훨씬 적거나 None인 경우가 많음 |
| 실습 1 · 입력 토큰 | 두 모델이 같거나 거의 같음 |
| 실습 1 · 두 답 | 둘 다 기준 세 가지. Flash 쪽이 더 자세한 경우가 많음, 문장은 달라도 됨 |
| 실습 1 · ③ Pro 호출 | 오류로 끝남. 무료 등급에 없는 모델 |
| 실습 2 · 졸업 학점 [지시 없음] | 학교마다 다르다는 일반 설명, 길게 나오는 경우가 많음 |
| 실습 2 · 졸업 학점 [지시 있음] | 존댓말 세 문장 안팎, 학과 공지나 학과 사무실에서 확인하라는 안내 |
| 실습 2 · 저녁 메뉴 [지시 없음] | 메뉴 추천 |
| 실습 2 · 저녁 메뉴 [지시 있음] | "학과 생활과 관련된 질문에만 답할 수 있습니다." 안내 |
| 실습 2 · ③ 여행지 [지시 있음] | 같은 거절 안내가 유지되는 경우가 많음 |
| 실습 3 · ① 두 답 | 데이터베이스: A반 / 운영체제: C반 / 통계학: A반 / 영어회화: A반 |
| 실습 3 · 생각 토큰 | high가 low보다 많은 경우가 많음 |
| 실습 3 · 응답 시간 | high가 더 긴 경우가 많음 |
| 실습 3 · ① 상태 | 두 호출 모두 `completed` |
| 실습 3 · ③ 상태 | incomplete. 상한에 걸려 끝까지 못 쓴 상태 |
| 실습 3 · ③ 답 | 다섯 가지를 다 못 쓰고 중간에 끊김 |
| 실습 4 · [제로샷] | 분류 이름과 함께 이유 설명이 붙는 경우가 많음 |
| 실습 4 · 졸업 요건 / 국가장학금 / 전공 필수 마감 | 학사 / 장학 / 수강 |
| 실습 4 · 복학 서류 / 동아리 박람회 / 근로 장학생 | 학사 / 기타 / 장학 |
| 실습 4 · ③ 계절학기 | 수강 |
| 실습 4 · 답 모양 | 퓨샷 줄은 모두 한 단어 |
