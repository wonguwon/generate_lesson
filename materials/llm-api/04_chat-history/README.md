# 대화 기록과 멀티턴 챗봇 - 실습 파일 (4차시)

교안: [4️⃣ API4 : 대화 기록과 멀티턴 챗봇](https://app.notion.com/p/add435fcbd9d83f39e8f016fb9b6e783)

학습자는 교안을 보며 `llm-api/04_chat-history/`에 파일을 직접 만들고 코드를 입력합니다. 실습 3의 `SYSTEM_INSTRUCTION`은 3차시 실습2에서 복사합니다. 이 폴더의 파일은 그 완성 상태입니다. 시작용 뼈대나 데이터 파일은 없습니다.

## 파일

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| 실습1_무상태.py | 무상태 호출 · 실습 1 ① | 이름을 알려 주는 호출과 이름을 묻는 호출을 따로 보냄 |
| 실습2_기록직접관리.py | 대화 기록 직접 관리 · 실습 2 | `store=False` + history 리스트. ③의 단계 수·type 목록 출력 두 줄까지 넣은 상태 |
| 실습3_터미널챗봇.py | 서버 측 상태와 터미널 챗봇 · 실습 3 ① | `previous_interaction_id`로 잇는 학과 안내 도우미 터미널 챗봇, 종료어 "그만" |
| 실습4_방식비교.py | 직접 관리 vs 서버 저장 · 실습 4 ① | 같은 5턴을 직접 관리·서버 저장으로 보내 턴별 입력·캐시 토큰 출력 |

- 교안의 각 코드 블록과 같습니다. 실습 2는 ③에서 더하는 두 줄을 넣은 마지막 상태입니다.

## 실행

`llm-api` 폴더에서 실행합니다(VS Code 실행 버튼도 같은 위치에서 실행).

```bash
python 04_chat-history/실습3_터미널챗봇.py
```

다른 파일도 `python 04_chat-history/파일이름.py`로 실행합니다.

### 단계별로 바꾸는 줄

| 단계 | 파일 | 바꾸는 곳 |
| --- | --- | --- |
| 실습 1 ③ | 실습1_무상태.py | `second`의 input을 `제 이름은 한지우이고 컴퓨터공학과 1학년이에요. 제 이름과 학년이 뭐였죠?`로 바꾸기 |
| 실습 3 ② | 실습3_터미널챗봇.py | 실행 후 `수강 신청 전에 확인할 것을 알려 주세요.` / `방금 말한 것 중 첫 번째를 조금 더 자세히요.` / `오늘 저녁 메뉴 추천해 줘.` / `그만` 입력 |
| 실습 3 ③ | 실습3_터미널챗봇.py | `system_instruction=SYSTEM_INSTRUCTION,` 줄을 `system_instruction=SYSTEM_INSTRUCTION if previous_id is None else None,`로 바꿔 확인 후 원래 줄로 되돌리기 |
| 실습 4 ③ | 실습4_방식비교.py | 맨 아래 네 줄을 `print("[직접 관리 - 최근 2턴]")`, `run_local(keep=KEEP_TURNS)` 두 줄로 바꾸기 |

## 정답 요약

교안의 정답 표를 옮긴 것입니다. 실제 키로 아직 실행하지 않은 예측입니다.

| 확인할 곳 | 정답 |
| --- | --- |
| 실습 1 · 답 1 | 반갑다는 인사, 이름을 불러 주는 경우가 많음 |
| 실습 1 · 답 2 | 이름·학년을 알 수 없다는 답, 알려 달라고 되묻는 경우가 많음 |
| 실습 1 · ③ 답 2 | 한지우, 컴퓨터공학과 1학년 |
| 실습 2 · 답 2 | 한지우, 컴퓨터공학과 1학년이라고 답함. 문장은 달라도 됨 |
| 실습 2 · 단계 type 목록 | `user_input`으로 시작, 그 뒤에 `thought`·`model_output`, 다시 `user_input` 순서로 반복 |
| 실습 2 · 단계 수 | 6개 안팎. thought가 없는 턴이 있으면 더 적음 |
| 실습 3 · ② 1턴 | 존댓말 세 문장 안팎, 날짜는 학과 공지에서 확인하라는 안내 |
| 실습 3 · ② 2턴 | 1턴 답의 첫 번째 항목을 이어서 설명 |
| 실습 3 · ② 3턴 | "학과 생활과 관련된 질문에만 답할 수 있습니다." 안내 |
| 실습 3 · ③ 2턴 | 1턴 답을 이어서 설명. 기록은 이어짐 |
| 실습 3 · ③ 3턴 | 메뉴를 추천하는 경우가 많음. 세 문장 규칙도 풀릴 수 있음 |
| 실습 4 · [직접 관리] 입력 토큰 | 1턴부터 5턴까지 턴마다 늘어남 |
| 실습 4 · [직접 관리] 5턴 답 | 한지우, 1학년 |
| 실습 4 · [서버 저장] 입력 토큰 | 턴마다 늘어나는 경우가 많음. 직접 관리와 수가 꼭 같지는 않음 |
| 실습 4 · [서버 저장] 5턴 답 | 한지우, 1학년 |
| 실습 4 · ③ 1~3턴 입력 토큰 | ①의 [직접 관리]와 비슷함 |
| 실습 4 · ③ 4·5턴 입력 토큰 | ①의 [직접 관리] 4·5턴보다 적음 |
| 실습 4 · ③ 5턴 답 | 이름·학년을 모른다는 답인 경우가 많음 |

실습 4의 [서버 저장] 입력 토큰은 이어 붙인 기록이 usage에 잡히지 않는 표시 문제가 보고되어 있어(과정 설명 페이지 "촬영 전 확인할 것"), 촬영 키로 먼저 확인해야 합니다.
