# Streamlit 챗봇 앱 - 실습 파일 (5차시)

교안: [5️⃣ API5 : Streamlit 챗봇 앱](https://app.notion.com/p/9ac435fcbd9d826c846e018b62cfb6a2)

학습자는 교안을 보며 `llm-api/05_streamlit-chat/`에 파일을 직접 만들고, 실습 3·4는 앞 실습 파일을 복사해 고칩니다. 이 폴더의 파일은 그 완성 상태입니다. 시작용 뼈대나 데이터 파일은 없습니다.
이 차시부터 `pip install streamlit`이 필요합니다(과정 폴더의 requirements.txt에 포함).

## 파일

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| 실습1_한화면앱.py | Streamlit 기본과 실행 방식 · 실습 1 | 질문 칸·보내기 버튼·답, 마지막 실행 시각 표시 |
| 실습2_채팅앱.py | 채팅 UI와 세션 상태 · 실습 2 | ③ Gemini 연결 + ④ 사이드바 대화 초기화까지 넣은 마지막 상태. `messages`·`last_id` 두 칸 |
| 실습3_스트리밍.py | 스트리밍 응답 · 실습 3 | 실습2에 `stream_answer`(stream=True, `step.delta`의 text를 yield, `interaction.completed`에서 id 저장)를 더한 것 |
| app.py | API 오류와 예외 처리 · 실습 4 | 완성 앱. 교안 토글 "완성 app.py 전체"와 같음. 키 없음 안내, try-except와 `error_message` |

- 교안의 코드 블록과 같습니다. 실습 2·3은 교안이 단계별로 보여 주는 고치기를 모두 반영한 마지막 상태입니다.

## 실행

교안대로 `llm-api` 폴더에서 실행합니다.

```bash
streamlit run 05_streamlit-chat/app.py
```

실습 1~3 파일도 `streamlit run 05_streamlit-chat/파일이름.py`로 실행합니다.

### 단계별로 바꾸는 줄

실습 2의 ①② 메아리 화면은 별도 파일이 없습니다. 시연할 때 교안 코드 블록을 그대로 입력합니다.

| 단계 | 파일 | 바꾸는 곳 |
| --- | --- | --- |
| 실습 2 ① | (새 파일) | 교안의 메아리 채팅 코드. `messages = []` 일반 변수라 앞 말풍선이 사라짐 |
| 실습 2 ② | (위 파일) | `messages = []`를 `if "messages" not in st.session_state:` 두 줄로, 아래 `messages` 세 곳을 `st.session_state.messages`로 |
| 실습 3 ③ | 실습3_스트리밍.py | 조각이 거의 한 번에 붙으면 `SYSTEM_INSTRUCTION`의 "세 문장 이내"를 잠시 "열 문장 이내"로 바꿔 비교 후 되돌리기 |
| 실습 4 ① | .env | 키 맨 끝 글자 하나를 바꿔 저장 → 앱 멈추고 다시 streamlit run (이때 app.py는 실습3_스트리밍.py를 복사한 직후 상태. try-except는 ②에서 넣음) |
| 실습 4 ③ | .env | 키 줄 맨 앞에 `#` → 앱 멈추고 다시 streamlit run |

## 정답 요약

교안의 정답 표를 옮긴 것입니다. 실제 키로 아직 실행하지 않은 예측입니다.

| 확인할 곳 | 정답 |
| --- | --- |
| 실습 1 · 브라우저 주소 | `localhost:8501` |
| 실습 1 · ③ 보내기 뒤 | 버튼 아래에 시간표 주의점 두 가지. 문장은 달라도 됨 |
| 실습 1 · ④ 질문만 바꾼 뒤 | 실행 시각이 바뀌고 앞의 답이 사라짐 |
| 실습 1 · ④ 저장·Rerun 뒤 | 바뀐 제목이 보임 |
| 실습 2 · ① 두 번째 보낸 뒤 | 첫 번째 말풍선 두 개가 사라지고 새 말풍선 두 개만 보임 |
| 실습 2 · ② 두 번째 보낸 뒤 | 앞 말풍선이 남고 그 아래에 이어짐 |
| 실습 2 · ③ 1턴 | 학과 공지나 학과 사무실에서 확인하라는 안내, 세 문장 안팎 |
| 실습 2 · ③ 2턴 | 1턴 답의 확인처를 이어서 설명 |

| 실습 3 · 1턴 답 말풍선 | 글이 몇 조각씩 차례로 늘어남 |

| 실습 4 · ③ 앱을 열자마자 | "API 키가 없습니다…" 안내, 채팅 입력창 없음 |
