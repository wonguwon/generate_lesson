# 멀티모달과 영수증 가계부 - 실습 파일 (7차시)

교안: [7️⃣ API7 : 멀티모달과 영수증 가계부](https://app.notion.com/p/abc435fcbd9d83c6822c81257611b257)

교안의 코드는 모두 **프로젝트 맨 위 폴더**(`llm-api`)에서 실행한다고 가정합니다(VS Code 실행 버튼, `streamlit run 07_multimodal/app.py`).
이미지는 6차시 `reviews.csv`와 같은 프로젝트 맨 위 `data` 폴더에 있습니다.

## 파일

코드 파일은 교안 코드 블록을 단계 순서대로 이어 붙인 **마지막 상태**입니다. 변수 이름·프롬프트·클래스·print 줄은 교안과 같습니다.

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |

영수증은 교안 토글 "영수증 네 장에 인쇄된 내용"을 그대로 그린 가상 영수증입니다(감열지 느낌의 흰 종이, 맨 아래 작게 "(실습용 가상 영수증)"). 할인·부가세·카드 번호 줄은 없습니다.
receipt4는 단가 12,900이 보이면 1 x 12,900에서 금액을 계산해 채울 수 있어, 교안이 기대하는 "확인 필요"가 나오지 않습니다. 그래서 단가까지 흐리게 했습니다.

시작 파일은 없습니다(교안이 새 파일을 만들거나 실습 2를 복사하게 함).

## 실행


## 정답 요약

실제 API 키로는 아직 돌려 보지 않았습니다. 아래는 교안 정답 표와 영수증 내용으로 정해지는 값이고, 모델이 영수증을 읽는 결과(특히 품목 이름·흐린 값 처리)는 실행마다 달라질 수 있습니다.

| 확인할 것 | 정답(예상) |
| --- | --- |
| 실습 1 ① | 앞 3바이트 `b'\xff\xd8\xff'`, base64는 `/9j/`로 시작. 바이트 수는 사진마다 다름(지금 일러스트는 약 66KB) |
| 실습 1 ②③ | 종류별에 text·image 항목, image 쪽이 훨씬 큼. 이미지 없이 보낸 입력 토큰은 훨씬 적음 |
| 실습 2 ① | `$defs`에 Item, items는 `$ref: '#/$defs/Item'`, store·date·total·amount는 `anyOf`에 자료형과 null |
| 실습 2 ③ | OO카페 정문점 / 2026-10-26 / 카페, 아메리카노 × 2: 9000원 · 카페라떼 × 1: 5000원 · 치즈케이크 × 1: 6500원, 총액 20500 |
| 실습 2 ④ | OO편의점 학생회관점 / 2026-10-27 / 식비, 품목 8줄, 총액 19900 |
| 실습 3 ② | `['품목 합계 17,000원과 총액 14,000원이 다름']` (모델 호출 없이 확정) |
| 실습 3 ③ | receipt1·2·3 총액 20500 · 19900 · 40000 → 통과. receipt4는 흐린 값을 null로 두면 총액 None, `총액을 읽지 못함`·`금액을 읽지 못한 품목이 있음` 중 하나 이상 |
| 실습 4 ② | "OO카페 정문점 20,500원을 추가했습니다.", 품목 3줄 |
| 실습 4 ③ | 3 + 8 + 3 + 3 = 17줄. 카테고리별 합계 도서·문구 40,000 · 식비 19,900 · 카페 20,500 · 생활용품 24,800 이하(휴지 금액이 null이면 11,900) |
| 실습 4 ④ | 가계부.csv 17줄, Excel에서 한글 정상 |

## 다시 만들기

`llm-api` 폴더에서 실행합니다.

```bash
py -X utf8 _생성스크립트/make_07.py .
```

영수증 숫자(품목 금액 = 수량 × 단가, 합계 20,500 · 19,900 · 40,000 · 24,800, 품목 3 · 8 · 3 · 3 = 17줄, 카테고리별 합계, JPEG 첫머리·base64 `/9j/`)를 assert로 확인한 뒤 `data/campus.jpg`·`data/receipts/` 네 장과 이 폴더의 코드 파일 네 개만 덮어씁니다. 다른 파일은 지우지 않습니다.

필요한 것: Pillow, Windows 맑은 고딕(`C:\Windows\Fonts\malgun.ttf`, `malgunbd.ttf`)
