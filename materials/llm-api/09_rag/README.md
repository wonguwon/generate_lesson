# 임베딩과 RAG 원리 - 실습 파일 (9차시)

교안: [9️⃣ API9 : 임베딩과 RAG 원리](https://app.notion.com/p/9b2435fcbd9d836ca60901016f19c282)

교안의 코드는 모두 **프로젝트 맨 위 폴더**(`llm-api`)에서 실행한다고 가정합니다(VS Code 실행 버튼). 코드가 `open("data/handbook_paragraphs.txt")`로 읽으므로 자료는 `09_rag` 안이 아니라 프로젝트 맨 위의 공용 `data` 폴더에 있습니다.

## 파일

코드 파일은 교안 코드 블록을 단계 순서대로 이어 붙인 **마지막 상태**입니다. 상수·프롬프트·시스템 지시·print 줄은 교안과 같습니다.

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| ../data/handbook_paragraphs.txt | 실습 1 ②③ · 실습 3 | 가상 "OO대학교 학사 안내" 문단 10개(**실습용 가상 자료**, 실제 학교 규정과 관계없음). 교안 토글 원문 그대로, 한 줄 = 한 문단, 줄 맨 앞 `[주제]`. UTF-8(BOM 없음) |
| 실습1_환각확인.py | 실습 1 ①②③ | 그냥 묻기 2번 → 수강 신청 문단(`HANDBOOK[0]`) 붙여 묻기 → 문단 10개 모두 붙여 묻기, 입력 토큰 출력 |
| 실습2_임베딩유사도.py | 실습 2 ①②③ | `gemini-embedding-2`로 문장 하나 → 다섯 문장(`{"parts": [...]}`로 감싸기) → 5×5 코사인 유사도 표. `pip install numpy` 필요 |
| 실습3_미니RAG.py | 실습 3 ①~④ | 문서 접두어 `title: none \| text:`로 문단 임베딩, `search`(질문 접두어, 상위 3개), `answer`(시스템 지시 규칙), 세 질문 |
| 실습4_랭체인.py | 실습 4 ①②③ | `ChatGoogleGenerativeAI` invoke → `ChatPromptTemplate` → `prompt \| llm \| StrOutputParser()` → 재수강·계절학기. `pip install langchain langchain-google-genai`(4.x) 필요 |

- handbook_paragraphs.txt 안에는 10줄 외에 아무 글도 넣지 않았습니다. 교안이 `문단 수: 10`을 확인하고 11 이상이면 "파일 끝에 다른 글이 붙음"으로 보기 때문입니다. 가상 자료 표시는 이 README와 교안 실습 자료 안내에 있습니다.
- BOM이 있으면 `HANDBOOK[0]` 맨 앞에 붙으므로 메모장 등으로 다시 저장할 때 "UTF-8"(BOM 없음)을 고릅니다.
- 시작 파일은 없습니다(교안이 새 파일을 만들게 함).

## 실행

`llm-api` 폴더에서 실행합니다.

```bash
python 09_rag/실습3_미니RAG.py
```

다른 파일도 `python 09_rag/파일이름.py`로 실행합니다.

## API 키

- google-genai(`genai.Client()`)는 `.env`의 `GEMINI_API_KEY`를 읽습니다.
- LangChain(langchain-google-genai 4.4.2)도 `GEMINI_API_KEY`만 있으면 그 키를 씁니다(새 키 불필요, `load_dotenv()`는 필요). `GOOGLE_API_KEY`도 함께 있으면 "Both GOOGLE_API_KEY and GEMINI_API_KEY are set. Using GOOGLE_API_KEY." 경고와 함께 `GOOGLE_API_KEY`를 씁니다. 둘 다 없으면 `ValidationError … API key required`. 교안 설명과 같습니다.

## 다시 만들기

`llm-api` 폴더에서 실행합니다.

```bash
py -X utf8 _생성스크립트/make_09.py
```

교안 정답 표가 기대는 사실(1학년 2월 18일(목), 4.0 이상 21학점, 통산 6학기, 10줄, "기숙사" 없음)을 assert로 확인한 뒤 `data/handbook_paragraphs.txt`만 다시 씁니다.

## 확인한 것 (가짜 응답)

- 네 파일 모두 문법 확인. `llm-api` 폴더에서 `python -X utf8 09_rag/실습N.py`로 실행해 `data/` 상대 경로 확인.
- 임베딩·생성은 가짜 응답으로 바꿔 실행(문단 수 10, `(5, 3072)`, `(10, 3072)`, 표 대칭·대각선 1.00). `embed_content`에 문장 하나는 벡터 1개, `{"parts": …}` 세 개는 벡터 3개로 요청되는 것을 HTTP 흉내로 확인. 가짜 임베딩이라 검색 순위(휴학 1위 등)는 확인하지 못했습니다.
