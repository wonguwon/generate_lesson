# 실습 데이터 정답표 (data_facts)

`make_data.py`로 만든 가상 데이터의 실제 값이다. `check_data.py`가 CSV를 읽어 자동으로 쓴 파일이므로 손으로 고치지 않는다. 교안·노트북의 정답 숫자는 여기서 가져다 쓴다. 숫자는 소수 2자리 반올림, index는 `pd.read_csv` 기본 0부터 시작하는 행 번호다.

- 다시 만들기: `_tools/.venv/Scripts/python.exe _tools/make_data.py` → `_tools/.venv/Scripts/python.exe _tools/check_data.py`
- 인코딩: UTF-8(BOM 없음). 범주값은 한글.
