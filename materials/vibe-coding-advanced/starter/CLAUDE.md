# CLAUDE.md

Claude Code가 이 폴더에서 일할 때마다 먼저 읽는 규칙입니다.
"작업 규칙"은 다른 프로젝트에도 그대로 쓰고, "이 프로젝트"만 바꿔 씁니다.

## 작업 규칙

### 일하는 순서
- 기능은 구현계획.md의 태스크 순서로 만든다. 기술·데이터·화면은 PRD.md를 따른다.
- 정하지 않은 것은 짐작하지 말고, 시작하기 전에 짧게 먼저 묻는다.
- 결정이 바뀌면 PRD.md를 먼저 고치고 무엇을 바꿨는지 알린다.
- 요청한 범위 밖의 파일·기능·설치는 건드리지 않는다. 필요해 보이면 먼저 묻는다.
- 점검·리뷰·로그 확인 요청이면 읽기만 하고 아무것도 바꾸지 않는다.
- 고치기 전에 원인을 한 줄로 먼저 설명한다.
- 기획서.md·PRD.md·구현계획.md·CLAUDE.md는 내가 요청할 때만 고친다.

### 라이브러리
- PRD.md 기술 방식에 적힌 라이브러리를, 그 라이브러리 공식 문서의 현재 방식대로 쓴다.
- 적히지 않은 라이브러리를 더하거나 다른 것으로 바꿔야 하면 먼저 묻는다.

### 키와 개인정보
- 키 값은 .env.local에만 두고, 값은 내가 넣는다. .env.local은 .gitignore에 둔다.
- .env.local의 값은 읽거나 보여 주지 않는다. 새 키 칸이 필요하면 .env.local을 처음 만들 때만 빈 칸으로 두고, 그 뒤에는 칸 이름만 알려 준다.
- 키 값은 코드·문서·화면·로그·답 어디에도 적거나 찍지 않는다. 키처럼 보이는 문자열은 가려서 보여 준다.
- 비밀 키는 서버 쪽 코드에서만 읽고, 이름에 NEXT_PUBLIC_을 붙이지 않는다.
- 외부 API 클라이언트는 요청을 받을 때 만든다. 키가 없어도 빌드는 통과해야 한다.
- AI나 외부 도구로는 집계값만 보낸다. 사람 이름과 원본 행은 보내지 않는다.

### DB
- SQL은 supabase/ 폴더에 파일로 저장만 한다. 실행은 내가 Supabase SQL Editor에서 한다.
- 이미 실행한 SQL 파일은 고치지 않고, 바로잡는 SQL은 fix_로 시작하는 새 파일로 만든다.

### 테스트
- 테스트의 기대값은 내가 준 값 그대로 쓴다. 실행 결과에 맞춰 기대값을 바꾸지 않는다.
- 테스트가 있으면 끝내기 전에 npm test를 실행해 결과를 보여 준다.

### 끝나면
- 만들거나 고친 파일 목록을 알려 준다.
- 내가 화면에서 확인할 순서를, 관련된 PRD 완료 기준 문장과 함께 알려 준다.

### 커밋
- 커밋과 GitHub 올리기는 내가 요청할 때만 한다.
- 커밋 전에 .env.local과 키 값이 커밋에 들어가지 않는지 확인한다.

## 이 프로젝트

- 서비스: 소담상점 매출 분석 서비스 sodam-sales (1인 판매자의 매출 엑셀을 저장·분석)
- 문서: 기획서.md · PRD.md · 구현계획.md는 폴더 맨 위에 둔다. 앱 코드도 하위 폴더 없이 이 폴더에 둔다.
- 기술: Next.js(App Router) + TypeScript + Tailwind CSS, Supabase(@supabase/ssr), SheetJS(공식 CDN 주소로 설치), Recharts(클라이언트 컴포넌트), Gemini API(@google/genai), mcp-handler
- 키 이름: NEXT_PUBLIC_SUPABASE_URL · NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY · SUPABASE_SECRET_KEY · GEMINI_API_KEY
- SQL 파일: supabase/01_tables.sql → 02_rls.sql → 03_mcp_keys.sql, 바로잡는 SQL은 fix_…
- 표 권한: GRANT는 authenticated·service_role에만, anon에는 주지 않는다. 모든 표에 사용자 칸(기본값 auth.uid())이 있고, 화면에서 사용자 번호를 보내지 않는다. 누구의 행인지는 RLS가 정하므로, 조회 코드에 사용자 조건을 따로 붙이지 않는다.
- 플랫폼: 스마트스토어 · 쿠팡 · 자사몰 세 개
- 집계: 대시보드·AI 리포트·MCP는 같은 집계 코드를 함께 쓴다. Supabase 조회는 1000행 한도에 잘리지 않게 한다.
- 날짜: 엑셀에 보이는 날짜 그대로 저장하고, 시간대 때문에 하루 밀리지 않게 한다.
