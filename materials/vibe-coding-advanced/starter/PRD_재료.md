# 소담상점 매출 분석 서비스 - PRD 재료

PRD.md를 만들 때 Claude Code에 읽히는 재료입니다. 이 파일에 적힌 표·권한·완료 기준 문장은 PRD.md에 바꾸지 않고 그대로 옮깁니다.
키 값은 이 파일에도 PRD.md에도 적지 않습니다. 키 이름과 두는 곳만 적습니다.

## 기능 명세
- 기획서.md의 MVP 목록대로 필수·추후 반영을 나눠 적는다.
- 나머지 칸은 필수 기능만 다룬다.

## 화면별 요소
- 전체 디자인 방향: 깔끔한 업무 도구 느낌, 흰 배경에 초록색 포인트, 숫자는 카드로 크게

## 데이터 구조
세 표와 관계:
- 매출 표: 매출 번호, 사용자, 주문번호, 날짜, 플랫폼, 상품, 수량, 단가, 금액, 주문자. 금액은 엑셀에 적힌 값을 그대로 저장
- 리포트 표: 리포트 번호, 사용자, 기간, 플랫폼 조건, AI에 보낸 집계값, 리포트 글, 만든 날짜
- 공유 링크 표: 링크 번호, 사용자, 리포트 번호, 추측하기 어려운 긴 토큰, 만든 날짜, 해제 여부
- 관계: 사용자 1 → 매출 여러 행, 사용자 1 → 리포트 여러 개, 리포트 1 → 공유 링크 여러 개

규칙:
- 세 표 모두 사용자 칸을 처음부터 둔다. Supabase 사용자를 가리키고, 기본값은 auth.uid(), 비울 수 없다. 화면에서 사용자 번호를 보내지 않는다.
- 주문번호는 엑셀의 주문번호 칸 그대로, 비울 수 없다. 사용자와 주문번호 조합은 겹치지 않게(UNIQUE) 한다.
- 엑셀을 올릴 때 같은 사용자에게 같은 주문번호가 이미 있으면 새 행을 만들지 않고 엑셀 값으로 덮어쓰고, 없으면 추가한다. 미리보기에 새로 추가할 건수와 덮어쓸 건수를 보여 준다.
- 직접 추가한 매출의 주문번호를 비워 두면 "직접-날짜6자리-순번3자리" 형식(예: 직접-240315-001)으로 붙인다.
- MCP 연결 키 표(키 번호, 사용자, 키 해시, 이름, 만든 날짜, 해제 여부)는 MCP 서버 태스크에서 더한다. 데이터 구조 칸에는 이 한 줄로만 적는다.
- 표를 만드는 SQL에는 로그인한 앱(authenticated)과 서버 전용 secret 키(service_role)가 세 표와 번호 시퀀스를 읽고 쓸 수 있게 GRANT 줄을 함께 넣는다. 로그인하지 않은 앱(anon)에는 주지 않는다.

## 연동 대상
- Supabase: DB와 이메일·비밀번호 로그인, 프로젝트 sodam-sales
- Gemini API: AI 분석 리포트, 서버 쪽 코드(Route Handler)에서만 부름. 무료 등급이라 가상 샘플 데이터로만 씀
- MCP 서버: Claude Code 같은 AI 도구가 부르는 /api/mcp, 읽기 전용 집계 도구만, 사용자별 MCP 연결 키로 누구인지 확인
- 키는 .env.local에만 두고 저장소에 올리지 않는다.

## 권한
- 로그인한 사람은 자기 매출·리포트만 보고 고친다(Supabase RLS).
- 공유 링크로는 그 리포트 한 건만 로그인 없이 읽는다. 고치기와 다른 데이터 보기는 안 된다.
- Gemini API에는 월별·플랫폼별·상품별 합계 같은 집계값만 보내고, 주문자 이름과 매출 행은 보내지 않는다.
- MCP 연결 키로는 그 사람의 집계값만 읽는다. 주문자 이름·매출 행은 내보내지 않는다. 해제한 키는 막힌다.

## 완료 기준
화면에서 확인할 수 있는 문장으로 기능마다 하나 이상. 아래 여섯 문장은 글자 그대로 넣는다.
- 소담상점_2024_상반기.xlsx를 올리면 미리보기 행 수와 저장된 행 수가 같고, 합계 카드·3월 합계·플랫폼별 합계가 강사 제공 정답 합계표와 같다
- 같은 파일을 한 번 더 올려도 매출 행 수와 합계 카드가 처음과 같다
- 다른 계정으로 로그인하면 내 매출·리포트가 하나도 보이지 않는다
- 로그아웃한 브라우저에서 공유 링크를 열면 그 리포트만 보이고, 링크를 해제하면 열리지 않는다
- GitHub 저장소 어디에도 API 키 값이 없다
- Claude Code에 내 MCP 연결 키로 sodam-sales MCP를 연결하고 2024년 3월 쿠팡 매출을 물으면 강사 제공 정답 합계표의 3월·쿠팡 합계와 같고, 키를 해제하면 답하지 못한다

## 기술 방식
- Next.js(App Router) + TypeScript + Tailwind CSS
- DB·로그인: Supabase
- 엑셀 읽기: SheetJS, npm 공개 저장소의 xlsx가 아니라 SheetJS 공식 문서의 CDN 주소로 설치
- 엑셀은 브라우저에서 읽어 미리보기로 보여 주고, 저장할 때 서버에서 값을 다시 검증
- 차트: Recharts, 차트는 클라이언트 컴포넌트로
- AI: Gemini API(공식 SDK @google/genai), 서버 쪽 코드에서만. 모델 ID는 Gemini API 공식 문서의 모델 목록에서 확인해 여기에 적음
- MCP 서버: Vercel mcp-handler 공식 문서 방식으로 Route Handler에
